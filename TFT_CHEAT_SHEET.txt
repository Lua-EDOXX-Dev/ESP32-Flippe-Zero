1. TFT starten

Das ist dein Grundgerüst:

from machine import Pin, SPI
import st7789

spi = SPI(
    2,
    baudrate=10_000_000,
    polarity=0,
    phase=0,
    sck=Pin(12),
    mosi=Pin(11)
)

display = st7789.ST7789(
    spi,
    240,
    280,
    reset=Pin(8, Pin.OUT),
    dc=Pin(9, Pin.OUT),
    cs=Pin(10, Pin.OUT),
    rotation=0,
    x_offset=0,
    y_offset=20
)

display.init()

🎨 4. Farben

Dein Treiber benutzt RGB565.

Eingebaute Farben
st7789.BLACK
st7789.WHITE
st7789.RED
st7789.GREEN
st7789.BLUE
st7789.YELLOW
st7789.CYAN
st7789.MAGENTA
Eigene Farbe

Format:

0xRRRR

Genauer: RGB565-Hexwert.

Beispiele:

ORANGE = 0xFD20
PURPLE = 0x780F
DARK_BLUE = 0x0010
GRAY = 0x8410

Dann:

display.fill(ORANGE)

y = 30
Breite = 100

🖼️ 10. RGB565-Bild anzeigen

Deine Datei:

boot.rgb565

laden:

with open("boot.rgb565", "rb") as f:
    bild = f.read()

anzeigen:

display.blit_buffer(
    bild,
    0,
    0,
    240,
    280
)

Für dein komplettes Bild:

with open("boot.rgb565", "rb") as f:
    bild = f.read()

display.blit_buffer(bild, 0, 0, 240, 280)
📦 11. Bildgröße berechnen

RGB565 braucht:

2 Bytes pro Pixel

Also:

240 × 280 × 2
= 134400 Bytes

Deshalb sollte dein Bild ungefähr sein:

134400 Bytes

🔢 13. Variablen benutzen

oder:
